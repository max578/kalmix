# De-Vibe pass — kalmix, 2026-07-05

One full human-judgement pass over every `R/` source, the four vignettes,
NEWS.md and the new README, run as part of the 0.3.0 surface work (WP-F of the
2026-07-05 review). Method: every file read line by line against the running
code, comments checked for claims the code does not make, prose checked for
filler and evaluative self-framing.

## What was found and changed

- **Comments that mis-stated the code.** The regime-model builder claimed the
  mean-reversion pull was "folded into the prior mean" (it was not; fixed with
  the deviation-form rewrite). An internal roxygen said the `"mbic"` penalty
  maps to `2 log(n)` while the code uses `3 log(n)`. The GPB1 header claimed
  equivalence to the IMM filter. All corrected against the code and the cited
  sources.
- **Evaluative self-framing.** Every prose use of "honest"/"honestly" in
  sources, vignettes and NEWS neutralised; the `[unverified]` token itself is
  API and stays.
- **External-project vocabulary.** References to a private provenance
  vocabulary document and to the wider project constellation removed from all
  shipped surfaces; the grounding tokens are now defined in the package's own
  words where they are used.
- **Prose tells.** Thirty-one spaced double-hyphen asides across the four
  vignettes restructured into commas, colons, parentheses or split sentences;
  no sentence-initial coordinating conjunctions were present.
- **Structure.** `aci.R` (690 lines) split at the natural seam into `aci.R`
  and `cir.R`; dash-banner sectioning added to the nine multi-definition files
  that lacked it.

## What was checked and left alone

- Validation is delegated to per-verb checkers (`.check_*`), one guard per
  condition, no duplicated conditions across functions.
- Error messages name the argument and the admissible values throughout.
- The remaining audit flags on roxygen completeness are S7 `print` method
  registrations, which are documented through the generic; flagged upstream
  as a detector gap rather than padded with boilerplate docs.
